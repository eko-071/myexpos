# Introduction to ExpL

- ExpL is a high level language.
- `library.lib` contains assembly language implementation of ExpL library and occupies 2 pages of memory.
- OS design stipulates that this library code must be pre-loaded to XSM disk blocks 13 and 14 using XFS interface.
- OS startup code loads this code into memory pages 63 and 64.
- An ExpL program will contain library calls using the `exposcall()` function.
- Compiler expects the library to be loaded to the **logical address 0** of the address space of the program.
- The target code generated by the compiler will not contain the code for the library. Instead, the OS is expected to link this code (at physical pages 63 and 64) into logical pages 0 and 1 when the program is loaded for execution.

## Start

1. ExpL program to print numbers upto 50. Saving it as `numbers.expl` and making it the init program.

```
int main()
{
decl
    int temp,num;
enddecl
begin
    num=1;
    while (num <= 50) do
         temp = exposcall( "Write" , -2, num );
         num = num + 1;
    endwhile;
    return 0;
end
}
```
```bash
cd expl/
./expl expl_progs/numbers.ex
cd ../xfs-interface
./xfs-interface
```

```bash
cd ../xsm
```

2.  Write an ExpL program to include a user defined type Student as follows:
```
Student
{
    str name;
    int marks;
}
```
Declare a variable of type Student, assign values "John", 89 for name and marks respectively and print the values to the terminal. Run the machine with this as an init program. Don't forget to initialize the heap and allocate the memory for a variable before assigning values to its attributes.
```
type
    Student
    {
        str name;
        int marks;
    }
endtype

int main()
{
    decl
        Student guy;
        int temp, heap;
    enddecl
    begin
        heap = initialize();
        guy = alloc();
        guy.name = "John";
        guy.marks = 89;
        temp = exposcall("Write", -2, guy.name);
        temp = exposcall("Write", -2, guy.marks);
        return 0;
    end
}
```
